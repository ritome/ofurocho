# お風呂帖 その他ページ 新デザイン化 設計書（v2-UI）

作成日: 2026-08-11

## 1. 目的とゴール

v1 で記録タブ（入浴記録）を「ユニット別グループ＋1名1行の行リスト」に刷新した。
本作業では、残る3ページを同じ視覚言語に揃え、アプリ全体で「迷わない・見やすい」体験に統一する。

北極星（v1 から継続）: 「1秒でわかる・タップを増やさない」。

対象ページ:
1. 予定編集モード（EditModeView）
2. 記録一覧タブ（ListTab）
3. 設定タブ（SettingsTab）

方針: **目的別に最適化（方針A）**。各ページを機能に合った形へ整え、色・字体・グループ・バッジのトークンを全ページで共有する。

## 2. スコープ

### やること
- **予定編集モード**: `card-grid`/`EditCard` を、記録タブと同じユニット別グループ＋行リストへ置換。
- **記録一覧**: 週/月/半年/年のマトリクス表を、可読性重視の「見やすい表」に強化（グループ見出し・固定ヘッダー・色ドット・ゼブラ・皮膚バッジ）。
- **設定**: カード見出し・余白・ボタン様式を共通トークンで統一。`.data-card-desc` の未定義CSSを追加。

### やらないこと（YAGNI）
- データモデルの変更（v1 で追加した `ユニット`/`皮膚評価要`/`主治医` をそのまま使う）。
- 記録一覧の集計ロジック・期間切替・Excel出力・印刷仕様の変更。
- 予定編集の並び替え・検索・フィルタ・印刷機能の仕様変更（見た目のみ影響）。
- 新しい画面・タブの追加。

データ互換ルール（厳守・v1 から継続）: 既存項目は削除しない。古いバックアップを読んでも壊れない（`性別`/`ユニット`/`皮膚評価要` 未設定でも既定値で描画）。

## 3. 共有デザイントークン（既存・v1 由来）

すべて index.html に既存。新規ページでも同じ値・同じクラスを使う。

| 用途 | 値 / クラス |
|------|------------|
| 男性の色帯・ドット | 青 `#9cc0f5`（`.is-male`） |
| 女性の色帯・ドット | 紫 `#c3a9ef`（`.is-female`） |
| 未浴・警告の帯 | 赤 `#d9534f` |
| 皮膚バッジ | `.badge-skin`（オレンジ「皮膚」） |
| 短期バッジ | `.res-row-short`（「短期」） |
| ユニット未設定の集約先 | 「その他」グループ（`groupByUnit` 既存） |
| 行リスト土台 | `.res-list` / `.res-group` / `.res-group-head` / `.res-group-rows` / `.res-row` 系 |

ユニット分けは既存ヘルパー `groupByUnit(items)` を再利用する。`items` は `{ resident, ... }` を要素に持つ配列で、`resident.ユニット` 未設定は「その他」に集約される。

## 4. ページ別設計

### 4.1 予定編集モード（EditModeView）

**現状**: `sorted`（`{ resident, planSession, isBathedToday, lastDays, level }` の配列）を `card-grid` 内で `EditCard` として並べる。行タップ = `onTogglePlanForEdit(residentId, dateStr, session)`。

**変更後**:
- `card-grid` を、記録タブと同じ `res-list` > `res-group`（ユニット別）> `res-group-rows` > 行 へ置換。
- 各行は新規コンポーネント `EditRow`（`ResidentRow` と対になる兄弟）で描画し、`res-row` 系CSSを再利用する。
- **並び順とグループの関係**: 既存の並び替え（最終入浴/部屋/カナ）とフィルタ・検索は維持する。フィルタ・検索・並び替えを適用した後の `sorted` を `groupByUnit` に渡してユニット別に束ねる。グループ内の行順は `sorted` の順序を保持する。
- グループ見出し `res-group-head` は「ユニット名 ／ N名予定」を表示（N = そのグループで当日いずれかの枠に予定がある人数）。進捗バーは出さない（予定編集は「済/未」ではなく「予定の有無」なので、記録タブの済バーは意味が合わない）。

**EditRow の構成（左→右）**:
- `res-row-gbar`（男女の色帯。`level` が `attention`/`critical` の時は警告色を優先）。
- `res-row-name`（氏名・太字）。
- 短期バッジ（`resident.区分 === "短期"`）。
- 最終入浴ラベル（`lastDays` を「未浴/本日/昨日/N日前」に整形。既存 `EditCard` のロジックを流用。`level` に応じ警告色）。
- スペーサー。
- 皮膚バッジ（`resident.皮膚評価要`）。
- 右端の予定トグル: 当日 AM 予定なら「午前」ピル、PM 予定なら「午後」ピル、当日別枠で入浴済み（`isBathedToday` かつ当該枠に予定なし）なら「本日入浴」ピル、いずれも無ければ「予定に追加」の淡いボタン。行タップで現在の枠（`session`）の予定を ON/OFF。

**行タップ挙動**: 現状維持。`onTogglePlanForEdit(resident.id, dateStr, session)` を呼ぶ。誤操作防止の「取消」二段構えは予定編集には不要（トグル前提の画面なので、タップで付外しできる現状の挙動を保つ）。

**維持する周辺UI**: `ModeBanner`（← 記録に戻る）、`DateNav`、印刷ボタン（午前/午後/両方）、`FilterBar`（並び替え・AM/PM・検索・フィルタ）、`edit-footer`。

### 4.2 記録一覧タブ（ListTab）

**現状**: 週/月/半年/年で、日付（列）×利用者（行）のマトリクス表。期間ナビ・Excel出力・印刷あり。

**変更後（表の可読性強化。構造・集計は不変）**:
- **ユニット別グループ見出し行**: 表本体に「すみれ/すずらん/…/その他」の見出し行を挿入し、その下に該当ユニットの利用者行を並べる。順序は `groupByUnit` に準拠。
- **固定表示**: ヘッダー行（日付列見出し）を `position: sticky; top: 0`、氏名列（先頭列）を `position: sticky; left: 0` にして、スクロール時も日付・氏名が見えるようにする。
- **男女の色ドット**: 氏名の左に小さな丸（男=青 `#9cc0f5` / 女=紫 `#c3a9ef` / 未設定=無色）。
- **皮膚バッジ**: `resident.皮膚評価要` の利用者の氏名横に `badge-skin`。
- **ゼブラ**: 利用者行に交互の背景色。グループ見出し行は非ゼブラ。
- **済マーク**: セルの入浴済み表現を明快に（`●` など既存の記号を踏襲しつつコントラストを上げる）。

**維持**: 週/月/半年/年切替、前後ナビ、今日へジャンプ、Excel出力、印刷（半年/年の横向き含む）、スタッフ業務量ビュー。スタッフビューはグループ化・色ドットの対象外（利用者属性ではないため）。

**印刷への配慮**: sticky と色ドット・ゼブラが印刷を崩さないこと。`@media print` で sticky を解除し、既存の印刷レイアウトを保つ。

### 4.3 設定タブ（SettingsTab）

**現状**: `data-card` を縦に並べたカード集。`.data-card-desc` はJSXで使われているがCSS未定義。

**変更後（見た目の一貫性のみ・構造不変）**:
- `.data-card-desc` のCSSを追加（説明文の色・行間・下余白。既存 `.data-card-body` に準じる）。
- 各カードの見出し（`data-card-title`）・余白・ボタン様式を共通トークンで統一し、カード間の間隔を揃える。
- 機能（バックアップ/復元/Excel/職員編集/皮膚評価一覧/全削除）の追加・削除・並べ替えはしない。

## 5. 実装上の注意

- **DRY**: `EditRow` は `ResidentRow` と重複させず、`res-row` 系CSSと最終入浴整形ロジックを再利用する。
- **既存クラスの共有**: 新規CSSは最小限にし、`is-male`/`is-female`/`badge-skin`/`res-group*` など既存クラスを流用する。
- **回帰防止**: 予定編集のタップ＝予定トグル、記録一覧の集計・出力、設定の各操作は挙動を変えない。
- **SWキャッシュ**: リリース時に `sw.js` の `CACHE_NAME` を次版（`ofurocho-v5`）へ更新する（`?cb=N` ではSWキャッシュを破棄できないため）。

## 6. 検証（ブラウザ確認。単体テストランナーは無し）

1. **予定編集**: サンプル投入 → 予定編集を開く → ユニット別グループ＋行リストで表示。行タップで午前/午後ピルが付外しされ、`今週N/目標`・皮膚・短期・最終入浴・男女帯が正しい。並び替え・検索・フィルタ・日付ナビ・印刷が動作。コンソールエラー0件。
2. **記録一覧**: 週/月/半年/年を切替 → ユニット別グループ・固定ヘッダー・氏名列固定・色ドット・皮膚バッジ・ゼブラが表示。Excel出力・印刷が従来通り。コンソールエラー0件。
3. **設定**: カードが統一された見た目で表示され、説明文（`data-card-desc`）が整う。全操作が従来通り。
4. **互換**: 旧バックアップ（新フィールド無し）を復元しても各ページがクラッシュせず、既定値（その他グループ・無色ドット・皮膚バッジ無し）で描画される。
5. **回帰**: 記録タブ（v1）が影響を受けていない。
